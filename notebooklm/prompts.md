
# Prompts utilizados no NotebookLM

## Prompt 01 — Fundamentos de Banco de Dados e SQL

### Prompt utilizado

> Com base exclusivamente nas fontes fornecidas, explique os conceitos fundamentais de banco de dados relacional e SQL para uma pessoa que está se preparando para trabalhar com análise de dados em uma instituição financeira. Dê exemplos relacionados a clientes, contas e transações bancárias.

### Objetivo

Utilizar as fontes adicionadas ao NotebookLM para compreender os principais conceitos de bancos de dados relacionais e SQL, relacionando a teoria com situações encontradas no setor bancário.

### Principais conceitos explorados

A resposta gerada pelo NotebookLM abordou conceitos como:

* bancos de dados relacionais;
* SGBDR;
* tabelas, linhas e colunas;
* chaves primárias e estrangeiras;
* relacionamentos entre tabelas;
* normalização;
* integridade e consistência dos dados;
* conceitos de transações e ACID;
* `SELECT`;
* `WHERE`;
* `ORDER BY`;
* `JOIN`;
* `LEFT JOIN`;
* funções de agregação;
* `GROUP BY`;
* `INSERT`;
* `UPDATE`;
* `DELETE`;
* triggers e auditoria.

### Aplicação prática

Os conceitos foram relacionados a um cenário fictício de instituição financeira, utilizando exemplos de:

* clientes;
* contas bancárias;
* transações;
* saldos;
* relacionamentos entre clientes e contas.

Esses conceitos foram posteriormente aplicados no projeto prático **Banco Aurora**, desenvolvido com PostgreSQL.

### Aprendizado

O uso do NotebookLM ajudou a transformar conceitos teóricos em exemplos relacionados ao contexto de análise de dados bancários, servindo como apoio para a construção do banco de dados e das consultas SQL utilizadas no projeto.
