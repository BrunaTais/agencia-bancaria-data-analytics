
# Prompts utilizados no NotebookLM

## Prompt 01 — Banco de dados e SQL

### Objetivo
Compreender os conceitos fundamentais de banco de dados relacionais e SQL aplicados ao setor bancário.

### Prompt

> Com base exclusivamente nas fontes fornecidas, explique os conceitos fundamentais de banco de dados relacional e SQL para uma pessoa que está se preparando para trabalhar com análise de dados em uma instituição financeira. Dê exemplos relacionados a clientes, contas e transações bancárias.

### Resultado esperado

Compreender conceitos como:

- tabelas;
- registros;
- campos;
- chave primária;
- chave estrangeira;
- relacionamentos;
- SQL;
- SELECT;
- WHERE;
- JOIN;
- funções de agregação.

### Aplicação prática

Os conceitos foram aplicados no projeto fictício Banco Aurora, utilizando as tabelas:

- clientes;
- contas;
- transacoes.
