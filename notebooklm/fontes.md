# Fontes utilizadas

## 1. PostgreSQL
Material utilizado para estudar conceitos de banco de dados relacional e SQL.

## 2. Microsoft Power Query
Material utilizado para compreender conceitos de tratamento e transformação de dados.

## 3. Microsoft Power BI
Material utilizado para estudar conceitos relacionados à análise e visualização de dados.

## 4. Python
Material utilizado como apoio ao estudo de programação e análise de dados.

## 5. Pandas
Material utilizado para estudar manipulação e análise de dados em Python.

## Objetivo

As fontes foram selecionadas para apoiar o estudo de análise de dados e Business Intelligence, relacionando conceitos técnicos a um cenário fictício de uma instituição financeira.
