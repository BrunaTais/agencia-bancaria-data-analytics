# Fontes utilizadas no NotebookLM

## Objetivo

As fontes foram selecionadas para apoiar o estudo de **Análise de Dados e Business Intelligence aplicado ao setor bancário**, fornecendo referências sobre banco de dados, SQL, tratamento de dados, Python, Power Query e análise financeira.

---

## 1. PostgreSQL

**Tema:** Banco de dados relacional e SQL

**Objetivo no projeto:**
Apoiar o estudo dos fundamentos de bancos de dados relacionais, criação de tabelas, relacionamentos, consultas SQL e manipulação de dados.

**Aplicação no Banco Aurora:**
Utilização do PostgreSQL para criar as tabelas `clientes`, `contas` e `transacoes`, além de realizar consultas para análise dos dados bancários.

---

## 2. Microsoft Power Query

**Tema:** Tratamento e transformação de dados

**Objetivo no projeto:**
Apoiar o estudo de processos de importação, limpeza, transformação e preparação de dados para análise.

**Aplicação no Banco Aurora:**
Preparação dos dados que poderão ser utilizados posteriormente em análises e dashboards no Power BI.

---

## 3. Microsoft Power BI

**Tema:** Business Intelligence e visualização de dados

**Objetivo no projeto:**
Apoiar o estudo da criação de relatórios, dashboards, indicadores e visualizações para tomada de decisão.

**Aplicação no Banco Aurora:**
Utilização dos dados bancários para construção de indicadores e visualizações relacionadas a clientes, contas e transações.

---

## 4. Python

**Tema:** Programação aplicada à análise de dados

**Objetivo no projeto:**
Apoiar o estudo de Python como ferramenta para tratamento, análise e automação de tarefas relacionadas a dados.

**Aplicação no Banco Aurora:**
Possível utilização do Python para análise exploratória, tratamento dos dados e geração de informações complementares às análises realizadas com SQL.

---

## 5. Pandas

**Tema:** Manipulação e análise de dados

**Objetivo no projeto:**
Apoiar o estudo da biblioteca Pandas para leitura, organização, transformação e análise de dados estruturados.

**Aplicação no Banco Aurora:**
Utilização futura para trabalhar com os dados extraídos do banco de dados e realizar análises exploratórias.

---

## 6. Banco Central do Brasil

**Tema:** Educação e informações relacionadas ao sistema financeiro

**Objetivo no projeto:**
Fornecer contexto sobre o sistema financeiro e conceitos relacionados ao uso de serviços financeiros e dados bancários.

**Aplicação no Banco Aurora:**
Utilização como referência para contextualizar o projeto fictício dentro de um cenário de análise de dados bancários.

---

## Como as fontes foram utilizadas

As fontes foram utilizadas como base de estudo e consulta no NotebookLM. A partir delas, foram elaborados prompts para compreender conceitos de banco de dados, SQL e análise de dados, relacionando os conhecimentos estudados ao projeto fictício **Banco Aurora**.

O objetivo não foi reproduzir o conteúdo das fontes, mas utilizá-las para:

* compreender conceitos técnicos;
* formular perguntas de estudo;
* relacionar teoria e prática;
* solucionar dúvidas;
* criar exemplos aplicados ao setor bancário;
* documentar o processo de aprendizagem.
