# Agência Bancária Data Analytics

Projeto prático de estudo e aplicação de conhecimentos em **Análise de Dados e Business Intelligence**, utilizando como cenário uma instituição financeira fictícia.

O projeto será desenvolvido progressivamente por meio da resolução de problemas de negócio inspirados em situações reais de uma instituição bancária.

## 🎯 Objetivo

Desenvolver conhecimentos práticos em:

* SQL e banco de dados;
* Excel avançado;
* Power Query e ETL;
* Power BI;
* DAX;
* Python e análise de dados;
* indicadores e KPIs;
* estudos ad-hoc;
* produtos e serviços financeiros;
* interpretação e comunicação de resultados.

O projeto também será utilizado como material de aprendizagem e portfólio profissional.

## 🏦 Cenário

A instituição financeira fictícia **Banco Aurora** possui clientes, contas, agências, produtos, transações, empréstimos e pagamentos.

Durante o projeto, serão apresentados problemas de negócio para serem investigados e solucionados utilizando dados.

A proposta é aprender as ferramentas **na prática**, aplicando cada conhecimento diretamente aos problemas da instituição.

## 🔎 Problemas de negócio

Ao longo do projeto serão investigadas questões como:

1. Quais agências apresentam maior volume de movimentação?
2. Como está o desempenho das agências em relação às metas?
3. O volume de transações está crescendo ou diminuindo?
4. Quais produtos possuem maior utilização?
5. Existem clientes com baixa utilização dos produtos?
6. Onde está concentrada a inadimplência?
7. Existem inconsistências ou problemas de qualidade nos dados?
8. Quais fatores podem explicar alterações nos indicadores?
9. Quais informações podem apoiar a tomada de decisão dos gestores?
