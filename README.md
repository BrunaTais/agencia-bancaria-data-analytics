# Agência Bancária Data Analytics

Projeto prático de análise de dados bancários utilizando SQL, Python, Excel, Power BI, Power Query e DAX.

## Objetivo

Desenvolver, de forma prática, conhecimentos em análise de dados e Business Intelligence por meio da resolução de problemas reais de negócio de uma instituição financeira fictícia.

O projeto será desenvolvido progressivamente, envolvendo:

* Banco de dados e SQL
* Tratamento e transformação de dados
* Excel e tabelas dinâmicas
* Python para análise de dados
* Power BI
* Power Query
* DAX
* Indicadores e KPIs
* Estudos e análises ad-hoc
* Contexto de produtos e serviços bancários
* Documentação e apresentação dos resultados

## Projeto

A análise será realizada sobre uma instituição financeira fictícia, utilizando dados de clientes, contas, transações, produtos, empréstimos e outros elementos relacionados à operação bancária.

O projeto será construído enquanto os conhecimentos são estudados e aplicados na prática.
